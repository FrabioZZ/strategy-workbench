## 联验记录

样例为 `600000.SH` 日线，采用「收盘价站上 5 日均线且放量时买入」「收盘价跌破 5 日均线时全部卖出」「目标仓位 20%」。样本行情包含指标预热、放量和供次日撮合的开盘价。

- 以合成样例及预置摘录调用一次本机已配置的真实 DeepSeek，完成实际术语选择和现有规则编译。返回就绪，保留 20% 目标仓位、5 日周期和跌破清仓，采用 `above` 与 `previous_20_x1_5`，两项均标为假设。此检查覆盖真实模型的消歧步骤，隔离演示的完整链路仍使用固定替身，选择 `cross_above` 与 `previous_20_x1_5`。
- 协调在修复后复跑 551 项 Python 测试及 5 项 Node 浏览器回归，全数通过。126 条 Backtrader 警告来自既有 `utcnow()` 弃用提示。`git diff --check` 无空白错误。正式资料库和交易库的大小、修改时间及独立验收的文件 SHA-256 前后一致。

- Chrome 独立点按使用空账本，回测和历史模拟各显示 20 根日线、20 条逐日信号记录和两笔模拟成交。11 月 18 日开盘以 10.35 元买入 1,900 股，11 月 24 日开盘以 10.20 元卖出 1,900 股。人工改选或修改原文后，旧组合的新执行返回 HTTP 409，原执行快照仍可打开。无模型和无行情反馈已验证。[实际 Chrome 回测截图](../output/playwright/phase-11-acceptance/phase-11-backtest.png)
