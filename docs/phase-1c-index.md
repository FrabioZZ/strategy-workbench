## 执行计划

使用 writing-plans 技能；按用户已授权的可见实现/基本验收方式执行，不重复流程批准。

**Goal:** 提供可复测的服务端小样本验证包，明确本机可用性与云端缺失证据。

**Architecture:** 串行 CLI 为每个样本启动有超时的独立子进程，调用现有 `app.adapters.download.download_in_worker`（其内置连接地址防护与实际媒体探测）；父进程归一化并汇总报告。轻量环境仅安装下载与媒体探测依赖，不启动应用、不加载 `.env` 或模型。

**Tech Stack:** Python 3.11+、yt-dlp、PyAV、pytest；可选 Docker/Linux VM。Spec 为本文件范围及本聊天任务说明。

协调补充文档：`phase-1c-tencent-vm.md` 提供用户已选腾讯云试用Ubuntu的私有CLI准备与证据收集步骤；具体CLI参数以实现后的runbook为准。
