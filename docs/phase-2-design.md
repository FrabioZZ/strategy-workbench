## 依据与范围

用户要求将多视频策略筛选、组合、冲突处理、勾叉启用及百分比权重纳入 Phase 2；回测与模拟盘必须使用用户指定的策略。手机底部 Dock 与桌面导航分别进入资料、策略组合、回测、模拟盘四个工作区。用户已答复 A 股优先。主聊天曾明确授权由助手决定开发流程并主导开发，先做本地 MVP；云迁移、常驻服务与手机原生计算以后处理。因此本轮直接实施、基本验收，无额外流程审批。

现有 FastAPI + SQLite + 原生 JS/CSS 页面保存带原文证据的策略草案。既有资料导入、转写、提取、导出和媒体播放必须保留。资料草案不是可直接运行的交易程序，不得默默把任意自然语言替换成均线模板。

已读取用户原始截图、主聊天及 LangAlpha 竞赛技术方案.docx。附件是技术参考，其中部署路径、令牌、运行命令、账户示例不作为操作授权。采纳数据冻结、下一时段撮合、回测/模拟盘独立账本、信号版本、意图去重和状态恢复的设计；不假定已有 LangAlpha、moomoo、行情权限或 AI 配置。

## 实施选择

直接接入外部券商会先依赖账户与行情权限；仅做导航壳不能验证策略执行。本轮选择现有本地架构上的确定性执行内核、本地模拟账户、明确的数据接入口。保留外部券商适配边界，但没有真实账户联调时不显示已连接。先支持 A 股普通股票日线、只做多，不宣称完整覆盖所有板块及公司行为。真实行情与显式标注的演示数据分别展示。

## 策略组合

- 从多个资料的策略草案建立组合，保留 document_id、草案/转写版本、原文规则和证据快照；也可明确创建手工策略，用于没有 AI 时实际验证。
- 每个组合项有 enabled、weight、可执行规则和人工确认状态。勾选模式对启用项等权；权重模式对启用项要求合计 100%，提供显式均分/归一化操作。禁用项不参与；空组合、全零权重、NaN/无穷值拒绝运行。
- MVP 执行器支持明确参数的均线趋势及价格阈值条件，支持配置目标仓位；未覆盖的自然语言、缺参数、未确认映射、过期草案均列入就绪检查。人工绑定须显示原规则和当前映射，不假称 AI 完成。
- 组合目标仓位为启用策略目标仓位的加权和，权重是资金/信号侧重，不是收益承诺。识别当前策略方向分歧并显示来源；冲突处理由用户选择阻止执行或采用权重结果，不以自然语言关键词把正常买卖规则误判为矛盾。
- 回测和模拟盘选择已保存组合及版本；启动时冻结快照，后来编辑不修改旧账本。

## 历史回测

- CSV 导入真实 OHLCV，至少含 date,symbol,open,high,low,close,volume；元数据包含 source、market、price_basis、is_demo。验证有限正价格、OHLC关系、非负量、重复日期标的、排序、区间、数据规模；只支持未复权成交价。拒绝静默使用复权价撮合。
- 保存数据版本、哈希、时间范围、标的和来源。可下载 CSV 模板；演示数据须由用户显式载入并在所有结果持续标注。
- 使用收盘及更早数据产生信号，下一可交易日开盘按费用/滑点假设撮合，决不以同根收盘信号买到同根开盘价。信号与成交分别记录时间。
- 每个 run_id 独立初始现金、空仓、信号、委托、成交、持仓、现金、净值及指标。先卖后买，限制现金/仓位、整手买入、T+1卖出；停牌/零量不可撮合；涨跌停与数据不足采取保守阻止并记录原因，不能承诺队列成交。只支持的证券规则应明确，拒绝超范围板块/缺失关键规则数据。
- 展示累计收益、最大回撤、交易费用、成交列表、净值序列及未成交原因。无交易、全现金也是有效结果。所有价格及费用假设可查；不展示虚构 Sharpe 等缺乏依据的指标。
- 当前不实现完整公司行为和财报 PIT。已知存在公司行为/异常缺口的输入不得作为无警告的正式回测。记录简化假设，避免声称机构级回测覆盖。

## 模拟盘

- 独立页面创建本地模拟账户/会话，指定组合版本、标的、初始现金、数据模式。显示启动、暂停、单步/立即同步、最近行情时间、心跳、资金、持仓、信号、委托及成交。
- 历史回放仅是演示验证，明确标注为“历史回放”，不叫实时跟盘。实时/增量模式使用可配置行情适配器或增量行情导入，只有新鲜且晚于上次处理的数据可推进。行情未配置或停更时进入等待/缺数据状态，不能生成假成交。
- 进程内轮询任务提供本地打开服务时的跟盘；启动/暂停、数据消费游标、意图与账本持久化。服务重启后保守暂停等待恢复，避免重复下单。主 UI 可定时刷新状态。
- 回测信号不直接送到模拟盘；由当前会话时钟与新行情重新计算。按会话/意图去重，重复提交/同步只产生一次有效成交，交易更新事务化。过期/乱序/未来行情、无仓卖出、资金不足需有可理解原因。
- 本地撮合的委托状态不冒充券商回报；券商适配状态明确未接入。无真实交易入口。日线增量跟盘不等于盘中实时行情，文案说明实际频率。

## 页面与接口

四个工作区：资料 / 策略组合 / 回测 / 模拟盘。手机 Dock 固定底部且留出 safe-area，桌面侧栏入口。点击时切换整个 main 内容，支持 hash 深链接、刷新保留当前模块；资料未保存编辑切换不丢失。状态反馈/错误中文，有标签、焦点与键盘操作。维持现有视觉风格。

后端实现首先发布 docs/phase-2-api.md，前端严格按该契约消费。接口统一置于 /api/trading，独立 APIRouter 挂入 create_app，保持既有路由。推荐资源：capabilities、strategies（草案候选）、portfolios（组合 CRUD/readiness）、datasets（CSV与演示导入）、backtests（创建/列表/详情）、paper/sessions（创建/列表/详情/start/pause/step/sync）。响应需完整可驱动界面，错误正文 detail 提供原因。开发者 API 文档同步真实 OpenAPI。

## 验收

1. 同一组合筛选/权重实际改变回测和跟盘结果；未确认/过期/全禁用组合不能启动。
2. 小数据人工复算一买一卖及费用；同输入重复回测成交序列一致；不得未来泄漏。
3. 模拟账户与回测隔离，重复行情/请求幂等，暂停/重启游标保存；没有最新行情不伪造成交。
4. 手机与桌面四个模块切换、组合保存、CSV导入、回测详情、模拟盘启动/暂停主流程可操作。
5. 既有测试与媒体/资料主流程无明显回归。独立可见聊天做基本验收，不做对抗审计。
