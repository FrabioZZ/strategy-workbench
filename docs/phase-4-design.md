# Phase 4：免费最新行情与模拟盘估值

日期：2026-11-10（Asia/Shanghai）。本设计依据用户明确执行授权，常规实现选择由助手负责，不重复申请设计批准。

## 目标与边界

在现有模拟盘页面直接查看免费、免第三方账号的A股最新报价，并让适合的增量模拟账户按持仓、成本和现金显示独立的最新估值及浮动盈亏。没有策略或账户也能从现有沪深300股票池选股看行情。保留历史订单、成交、净值、版本、游标；报价刷新绝不调用原日线撮合或生成策略。

不包含新的盘中策略自动买卖、券商连接、真实订单、研究数据转严格撮合数据。Backtrader和原历史回放保留原身份；若提供最新估值只能明确标为历史持仓参考，优先只为增量账户提供实时估值。

## 技术选择

- 首选腾讯公开批量快照HTTP接口：有源端行情时间、可少量批量请求，无需新依赖或账号。AKShare整套引入会增加依赖而不解决源可靠性，因此暂不选。以本机网络实测确定可用性，不用文档替代连通证明。
- 独立报价服务和路由；缓存、去重、限速、失败退避由服务端统一管理。默认约45秒刷新，具体实现可在30–60秒内按源能力选择。源调用超时有界；先读取会话快照并释放数据库连接，再联网；不持有SQLite写锁。
- 报价缓存独立于交易账本，所有返回明确区分行情时间、接收时间、最近尝试、最近成功、来源、市场时段及新鲜度。源失败保留旧价但明确失败/过期，零值、错标、未来/不可信时间不能作有效估值。
- 交易时段按Asia/Shanghai与核实的交易日历判断，覆盖2026年长假；已验证范围以外显示日历未知，不能仅按自然日龄判断休市报价。停牌或零成交如不能确认停牌原因，明确说明状态未知而不造状态。
- 估值每账户独立：市值为有效现价乘实际持股数，浮盈亏为市值减账面持仓成本；现金和历史费用沿用账本。不完整报价不输出看似完整的总资产，不把不同账户合并。
- 同页独立报价区提供搜索选择、手动刷新与自动刷新状态，报价改变只更新展示。说明服务运行时后台刷新范围，以及页面关闭/隐藏时行为。

## 接受标准

1. 本机真实网络保存公开返回、源时间、收到时间、请求和摘要，可核验最新可得报价。
2. 确定性测试覆盖解析、错标/零值/时间、长假、缓存与失败、部分失败、估值与历史不变。
3. 隔离数据库浏览器验证空账户可看行情、搜索选择、自动刷新、账户估值和320/390/1440布局。
4. 原回测、历史回放和资料主流程基本回归通过；仅基本验收，不做对抗审计。
5. 通过独立可见验收后在线备份正式库，标准隐藏启动器重启8765，核验仅本项目进程；正式只读检查与数据保全。
6. 若当前闭市，收盘价就是最新可得报价。交付说明盘中连续变化尚未现场观测，不用测试替身宣称盘中实测。
