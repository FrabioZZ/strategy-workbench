# Phase 4 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 逐项实施。用户指定可见实现/基本验收/必要修复聊天，复用当前目录，不提交Git。

**Goal:** 免费最新A股报价接入现有模拟盘，为增量会话提供独立只读估值。

**Architecture:** 独立报价模块、服务端共享缓存、只读账户估值API和原生JS面板。原交易引擎与账本保持职责不变。

**Tech Stack:** FastAPI、SQLite、Python、原生JavaScript；优先使用现有HTTP依赖或标准库。

**Spec:** `docs/phase-4-design.md`。

## Global Constraints

正式数据不作测试；所有测试使用隔离目录、端口及有界子进程。源访问有超时、缓存、限流和退避。仅公开免费接口，不注册、不付费。不扩大为盘中自动交易。

## Review Focus

- 长假与闭市最新可得价格：不能因日龄过期或把抓取时间当行情时间。
- 多账户、多标签页与手动刷新：共享缓存，不能绕过限流。
- 部分返回、错标、零值、异常时间：不得生成完整有效估值。
- 历史回放和冻结账本：刷新前后订单、成交、净值、版本和游标一致。
- 无组合/无账户与窄屏：能直接选股票看行情，不要求CSV/Tushare。
