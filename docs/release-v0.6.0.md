# 策略拾录 0.6.0

Windows x64 便携版：下载 ZIP，完整解压，双击 `StrategyWorkbench.exe`。双击 `StopWorkbench.exe` 完全退出；转写与回测运行中请先等待任务完成。

## 本版内容

- 回测起止日期、实际区间、区间盈亏金额、收益率和初始/结束资产。
- 32 项日线基础字段与技术指标，包括 MACD、KDJ、BOLL、RSI、ATR、MA/EMA、CCI、WR、OBV、量价以及可信限价下的首板/连板。
- 条件、上下穿、AND/OR 与历史偏移；回测和模拟引擎共用计算规则。
- 本机 AI Key 设置、语音校正、策略命名、能力表对照及人工确认执行参数。
- 内置 Python、语音模型、Node/Chromium、依赖和沪深300历史研究数据；缓存与数据库自动建立。

## 验证与范围

- 432 项项目测试通过；独立浏览器主流程和移动端布局通过。
- 日线确认样例实际在回测、本地历史回放与 Backtrader 产生买入和卖出；真实行情/真实视频收益未由测试夹具证明。
- 原《一进二》视频含竞价、盘口、5分钟回封等条件，当前日线引擎不能完整执行；系统提示缺项，不能宣称该原视频已全自动跑通。
- 没有用户 API Key，因此真实模型连通与提取质量仍需在填写 Key 后验证；已验证其接口与本地执行链路。
- 不连接券商，不下真实订单。公开视频和行情服务仍受网络、平台验证和数据可用性影响。

用户媒体、正式数据库和 Key 不在软件包或源码仓库中。用户数据保存在软件目录 `user-data/`，升级前请备份。完整记录见 `docs/phase-6-index.md`。
