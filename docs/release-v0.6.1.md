# 策略拾录 0.6.1

从资料提取交易策略，按已确认规则分析行情指标并运行回测或模拟交易，以盈亏、收益率和交易记录呈现结果。

## 本次更新

- 删除“一进二”功能测试说明与盘面预测验证叙事。
- 精简四个工作区的注释性小字、重复说明和开发术语，统一表单、操作状态与界面层级。
- 回测与模拟结果优先呈现盈亏和收益率，明细按需查看。
- 校准电脑及手机布局，保留资料、策略组合、历史回测和模拟盘的既有工作流。

## 安装和升级

本版已通过 432 项 Python 测试、2 项 Node 测试、独立浏览器主流程及 320–1440px 布局检查；实际 ZIP 在新目录中启动、语音模型加载、内置浏览器及退出验证通过。

下载 `StrategyWorkbench-0.6.1-windows-x64.zip`，完整解压至可写目录，双击 `StrategyWorkbench.exe`。Python、中文语音模型、匿名下载浏览器及历史研究数据均已内置；AI 提取需填写自己的模型 API Key。

升级前先结束任务并用旧目录的 `StopWorkbench.exe` 退出，备份旧目录中的 `user-data`，再将其复制到新版本目录以继续使用自己的资料和账本。不要同时启动两个版本处理同一份数据。新电脑或 Windows 用户需重新填写模型 Key。

当前版本提供日线回测和模拟交易，未连接券商。软件包和源码不包含开发者资料、数据库或 Key。完整实现、验收和发布记录见 [Phase 7](https://github.com/FrabioZZ/strategy-workbench/blob/main/docs/phase-7-index.md)。
