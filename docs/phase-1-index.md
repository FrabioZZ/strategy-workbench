## 技术决策

- 采用浏览器界面配合本地 Python 服务，便于将来迁移到服务器。平台选择由实现方作出，并非用户指定。
- 本地文件与文本/字幕导入提供可控入口；Bilibili/抖音 URL 通过 yt-dlp 适配。平台限制时明确失败并指向本地上传。
- 本地 faster-whisper 转写；保留分段与时间。AI 只接收文本和必要元信息。
- 支持可配置 OpenAI 兼容接口和 Ollama，不预设用户拥有任何账户或密钥。
- 原文没有的阈值/周期/仓位标为待澄清。输出为策略草案，不直接执行代码或下单。
- 视频画面独有信息无法由音频转写恢复，需人工补充；OCR/视觉识别不属本期。
