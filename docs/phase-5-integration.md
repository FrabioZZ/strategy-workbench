## 基本验收关注项（已复核）

1. 用户真实样例包含“油脂/游资”“打手把/打首板”“衡量化/和量化”等疑似识别错误。校正需实际覆盖常见金融语境错词，不应只能校正5个词而让主要用户诉求退化成标点修复。原文、数字和交易逻辑保护继续保留；不得将猜测交易参数自动执行。
2. 预设多供应商的连接测试参数需按官方协议兼容，不能因仅 OpenAI 接受的参数使其它选项测试必定失败；mock 验证不冒称真实连接。
3. 原 `validate_strategy` 自动给缺止损添加问题，但执行 DSL 止损可选。只可移除这一项经明确说明且未提供止损的保守提示，不能忽略其他来源问题。
4. 校正与原始引文的前端标记须消费后端 transcript_version，不能只用字符串猜测；查看证据仍能到原始段落。
5. 旧正式源码包不代表本阶段新应用版本；当前源码已交接 Phase6，最终统一发布、打包与部署归 Phase6。
