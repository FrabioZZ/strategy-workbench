# Phase 1C — 从本地原型到手机共用云端后台的差距

2026-11-09，基于当前代码检查；本文是后续实施清单，不代表这些能力已经上线。Phase 1C 只交付一次性媒体获取验证包，不开放应用 HTTP 服务、不迁移用户资料、不创建付费资源。免费平台及账户选择由主聊天单独推进。

## 可以先做的最小验证

在用户选定且有权限运行命令的 Linux VM/容器里，运行独立验证 CLI：一次一个样本，获取真实媒体后读取容器信息，输出可比对报告。它不需要公网监听、数据库、账号系统、ASR模型或AI密钥；只需要DNS解析、访问公开HTTPS视频站点及其媒体分发地址、可写临时磁盘和依赖安装能力。

先证明特定地区/网络出口/时间的实际获取结果，再决定移动网页第一版。公开页面能打开、任务已提交、短链解析成功都不能证明媒体已获取。单个B站样例成功不能外推到全站；抖音错误中提及fresh cookies不能证明登录一定能解决，云端出口也不保证消除限制。

## 上线差距与可验收结果

| 领域 | 当前代码事实 | 最小上线工作与验收条件 |
| --- | --- | --- |
| 身份认证及资料隔离 | `app/main.py` 没有账户会话/身份依赖；`Store.list_documents()`列出共享资料；documents、jobs、strategies均无owner字段 | 确定登录方式与会话生命周期，增加资料所有者及迁移方案；列表、读取、编辑、任务状态/重试、媒体播放、导出全部校验归属。用两个账户验证双方都不能访问或操作对方资料；不可只在前端隐藏 |
| 当前单用户数据迁移 | `data/`保存本机SQLite、uploads、media及任务临时文件；数据库媒体路径为本机绝对路径 | 先备份并验证恢复，再由用户明确选择是否迁移及归属账户；转换媒体路径为可迁移的存储键。迁移后对转写、版本、草案、任务和文件完整性逐项比对，保留可回退备份 |
| 持久化与恢复 | `Store`使用本地SQLite WAL；没有对象存储、用户配额或过期清理 | 小规模可先采用单机持久磁盘+SQLite，并约束单个写入服务；容器替换不能丢数据。媒体与数据库一致性备份、恢复演练、删除和保留期限必须落实；无持久磁盘的平台不能把临时文件系统当正式存储。扩容再评估托管数据库/对象存储 |
| 后台任务生命周期 | `Jobs`使用进程内`ThreadPoolExecutor(max_workers=1)`；任务记录在SQLite，但待执行队列只在内存；`recover()`将所有queued/running标为interrupted | 下载、ASR、AI拆分任务状态与资源预算，持久化领取、租约/心跳、取消、失败重试、幂等和容量限制。最小方案可以单worker轮询数据库，无需预先引入多种服务。断网或手机离开页面后已接收任务继续；worker重启不重复计费、跨进程不抢同一任务 |
| 多实例部署 | `scripts/run.py`持有数据目录文件锁并绑定127.0.0.1；恢复和调度依赖单进程语义 | 先保留单实例约束，明确部署方式。多worker或多个副本前需独立调度与租约设计；不能简单提高uvicorn worker数。任务恢复仅处理过期租约，不能新实例启动就中断另一实例正在跑的任务 |
| HTTPS与域名 | 仅允许localhost等Host；同源修改检查与CSP适用于本地界面；无远程登录状态 | 使用HTTPS入口与正式域名，明确反向代理信任范围、Host和Origin策略；Cookie会话配置安全属性与CSRF防护。测试真实手机域名登录、上传、轮询、音视频Range播放和下载。不能通过关闭所有Host/来源检查完成上线 |
| 手机入口与上传 | 当前网页支持粘贴分享文案和文件上传；上传请求到完成前手机需保持连接，未实现分片续传 | 第一版移动网页先验收粘贴、选择文件、上传进度、网络中断提示/重试和任务恢复。按实际最大文件测试弱网；需要时增加分片/直传及完成确认。接收任务与上传完成后可关页面；未完成上传不能承诺后台继续 |
| App分享与第三方媒体 | 尚无Android/iOS分享接收；网站分享链接不等于媒体文件，平台官方信息权限也不等于下载任意第三方内容 | 后续单独验证来源App能分享的类型、目标App接收及链接归一化。保留用户持有文件/字幕上传。不得依赖开发者共享Cookie、读取抖音App私有会话或不明签名服务 |
| 下载网络与资源 | 生产适配器检查实际socket目标、重定向/CDN连接，禁用环境代理和浏览器凭据；只取受支持的单文件格式；单文件限制不等于总磁盘限制 | 保留现有检查并增加平台侧出站策略（尤其云元数据、私网）。限制每用户/全局任务、并发、累计磁盘、重试次数及保留期；满额时明确拒绝或排队，不耗尽机器。验证包结果不代表整个应用已达到公网部署条件 |
| ASR | 每次任务在子进程中加载faster-whisper，本地模型必须事先存在；目前无模型 | 选型后用目标机器上的中文样例测峰值内存、速度及术语/数字准确率，再决定CPU模型、GPU或外部服务。模型许可、下载体积、常驻磁盘及维护独立确认；轻量下载CLI成功不证明ASR能在同一免费实例运行 |
| AI与费用控制 | 服务器配置一个AI服务，文本会发往该服务；调用有180秒超时与50000字限制，没有账户预算或账单统计 | 凭据仅后台保存；披露文本去向，按用户/全局设置额度和并发，记录可核对的用量，失败/超时明确是否重试。结构引用校验继续保留；避免重启自动重发付费请求 |
| 观测与运维 | 当前固定安全错误有利于避免泄漏，但缺乏跨任务资源指标、健康监测、用户层限流和可审计操作记录 | 使用任务ID关联安全日志，观测成功率、队列等待、耗时、磁盘/内存和预算；不记录凭据、原始第三方异常、CDN签名URL或完整私人转写。设置容量告警、备份状态和故障恢复流程 |

## 容量与费用如何验证

以下是估算方法，不是已测容量或厂商报价。下载验证与生产使用分别计量，免费额度需要在部署前核实区域、有效期、绑卡/自动升级及超额规则。

- **一次验证：** 最多5样本，串行；默认每样本32 MiB/600秒媒体/120秒任务/整批600秒。部署文档应设容器内存、CPU、进程数限制，并记录实际峰值；本机数据不足以断言某种免费规格稳定可用。
- **媒体存储：** 约等于每日导入数 × 实际平均媒体字节 × 保存天数，再加上传临时文件、失败片段、备份、模型及数据库。例如每天10份、每份20 MiB、保留7天，仅媒体约1.37 GiB；若按200 MiB上限估算则约13.67 GiB。备份副本会进一步增加占用。
- **出站流量：** 用户播放/下载媒体会消耗服务出口；媒体导入、对象存储请求/跨区传输也可能计费。相同文件反复播放不能只按“成功下载一次”计费估算。
- **任务吞吐：** 单worker可完成数量取决于实际下载、转写和AI耗时；分别测平均和长尾，不用CPU核数替代吞吐实测。容量不足时先限额排队，不自动扩容付费。
- **预算边界：** 免费计算、磁盘、出口、构建时长、备份、域名及模型调用分别核对。休眠型实例、短请求时限、无持久磁盘或不支持长后台任务的平台，需要相应独立worker和存储，不能视为完整后台已经免费覆盖。

## 后续实施顺序

1. **实际云端获取验证：** 获得平台/区域/规格及运行权限，在该环境执行同一包；记录运行时间、环境说明、包校验值、退出码、完整报告和真实媒体指标。即使失败也保存安全分类，区分网络/平台限制/依赖问题。回传时只需脱敏报告，勿上传用户凭据。
2. **移动网页最小云端试用：** 创建新的可见阶段协调/实现/验收聊天；先落实身份、数据持久化、任务可靠性、HTTPS与资源预算，再部署单用户或受控小规模试用；选择受控范围也要明确身份边界。
3. **真实转写/策略提取及App分享：** 在用户配置模型/服务后分别验收；App分享是独立入口工作，不能替代媒体获取验证。模拟盘/回测属于后续独立阶段。

## 当前结论

现有下载适配器可作为独立云端探测的复用基础；当前应用仍不能直接作为多用户手机云服务上线。本阶段不更改上述产品能力。用户已选择腾讯云一个月试用，但实例尚未创建；资格/规格/到期续费以该账号官方页面为准。因此没有实际云端成功率、内存占用、Linux构建成功或免费方案足够运行整个产品的结论。
