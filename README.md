# 策略拾录

一个在本机运行的中文交易策略工作台。从音视频或字幕提取策略，确认组合与执行参数后，按策略分析行情指标并在历史回测或模拟盘中执行交易，以盈亏、收益率和交易记录呈现结果。

## 0.6.1 Windows 便携版

下载 Release 中 `StrategyWorkbench-0.6.1-windows-x64.zip`，完整解压到可写目录，双击 **StrategyWorkbench.exe**。已内置 Python、所有运行依赖、中文 ASR 模型、匿名 Chromium/Node、300 只股票的历史研究行情；不需要安装 Python、配置语音模型或缓存路径。首次打开自动初始化本地数据，只需在模型设置中选择供应商并填写自己的 API Key。双击 **StopWorkbench.exe** 退出后台服务；请先等转写/回测任务结束。

用户资料、视频缓存、交易记录和本机加密 Key 保存在软件目录 `user-data/`；升级前请备份此目录。下载包不含开发者资料或凭据，ASR 可离线工作，公开视频下载、最新行情和模型调用需要网络。更换 Windows 用户/电脑后需重新填写 Key。

本版回测提供起止日期、实际交易区间、初始/结束资产、区间盈亏和收益率；起日前行情只用于指标预热。32 项指标覆盖 OHLCV、MA/EMA、MACD、KDJ、BOLL、RSI、ATR、CCI、WR、OBV、日量比/涨跌幅以及可信限价数据下的首板/连板。条件策略支持指标比较、阈值、上下穿、AND/OR、历史偏移；AI 与回测/模拟盘共用同一能力注册表。

本版将四个工作区按日常使用流程整理，删除功能测试说明和重复注释，结果页以盈亏为首要信息。软件按已确认规则执行，不以盘面预测准确率评价策略。当前支持日线回测与模拟交易，尚未连接券商实盘；真实大模型效果需要用户自己的 Key 验证。最新校准、验收与发布记录见 [Phase 7](docs/phase-7-index.md)，指标引擎实现记录见 [Phase 6](docs/phase-6-index.md)。

## Windows 启动

需要 Python 3.11 或更高版本（本机验证版本为 3.12.14），建议 CPU 至少 8GB 内存。初次安装需要联网；模型资源另行准备。

```powershell
cd C:\Users\Admin\Desktop\quant
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

打开 <http://127.0.0.1:8765>。当前开发交付已安装 `.venv`，可以直接运行 `start.ps1`。停止服务使用 Ctrl+C。

若 `py` 不可用，指定 Python 的绝对路径：

```powershell
.\scripts\setup.ps1 -PythonPath 'C:\path\to\python.exe'
```

本机验证所用 Python 在 Codex 的 bundled runtime 内；`.venv` 依赖该解释器位置，若 Codex 更新导致路径变化，请用自己的 Python 重新建立虚拟环境。不要把 `.venv` 复制到其他电脑。

## Linux 启动

```sh
sh scripts/setup.sh
sh scripts/start.sh
```

入口固定绑定 `127.0.0.1`，默认端口 8765；Windows 可传 `-Port 8767`，Linux 可设置 `PORT=8767`。启动器对同一数据目录持有文件锁，防止多个进程同时恢复/调度任务。不要以多 worker、自动 reload 或直接开放公网方式启动此一期程序。

## 使用流程

1. **导入资料**：上传 MP4/MKV/MOV/WebM、MP3/M4A/WAV/FLAC/OGG/AAC；或粘贴 Bilibili/抖音单视频 HTTPS 链接、完整分享文案；也可上传 UTF-8 TXT/SRT/VTT 或粘贴文本。
2. **获取与转写**：本地 ASR 已配置时，分享链接自动完成媒体获取和语音识别；处理中展示进度条及保持程序打开、设备唤醒的提示，完成后显示勾选。默认不显示播放器或整篇转写。需要校对时展开原文；字幕保留时间，普通文本不造时间。无 ASR 时媒体先保存在本机，配置后可从缓存开始转写。
3. **AI 校正与提取**：点击提取才会调用模型，先检查识别中的明显错词与断句，再按内容命名并摘录策略。原始转写保留，校正版与修正记录单独保存；不确定的交易含义留待确认。模型输出需通过 JSON 结构与对应版本的引文校验。
4. **核对草案与参数**：查看买卖、仓位、止损与待澄清项；证据注明原始或校正版本。进入策略组合可请求 AI 生成现有引擎支持的执行参数，核对并手动确认后保存，再用于回测或模拟盘。无法完整表达的规则不会硬套为可执行策略。
5. **导出 JSON**：包含原始转写、校正版、修正记录、时间戳、版本、模型来源与策略草案，不包含 Key。修改原文后旧草案标为过期，需重新提取才能导出当前版本。

示例按钮只载入标注为“示例”的文本，不生成伪造 AI 策略。即使模型未配置，资料与转写仍保存在本机。

## Phase 2 使用路径

手机底部 Dock、桌面侧栏提供「资料」「策略组合」「回测」「模拟盘」四个入口。回测与模拟盘是独立工作区。

1. **建立策略组合**：选已有资料草案，或明确添加手工策略。核对原规则，选择支持的可执行类型并填入参数，人工确认映射；草案本身保持不可执行。MVP 支持均线趋势、价格阈值及可选收盘止损，不能表达的规则不应勉强映射。
2. **筛选和分配权重**：勾选决定是否参与。等权模式对启用项均分；百分比模式对启用项要求合计100%。冲突可选择暂停该日信号，或按配置的权重合成目标仓位。保存组合后查看就绪提示；缺项、过期或未确认的组合不能执行。
3. **准备回测数据**：使用页面提供的 CSV 模板，导入未复权日线和数据来源；正式数据需要昨收及每日上下限价。当前限沪深主板普通股票，不支持 ST、上市初期特殊规则及公司行为。演示数据必须显式加载，并持续标为演示。
4. **运行历史回测**：选择组合版本、数据集、单个标的、初始现金及费用/滑点假设。信号在收盘生成，下一根开盘按约定撮合；查看实际计算的净值、费用、信号、成交和拒绝原因。旧结果保留启动时的策略和数据快照。
5. **创建模拟会话**：选择同一组合的版本，建立独立本地模拟账户。「历史回放」用于逐步验证；「增量跟盘」只接受新鲜的新行情。可启动、暂停、单步或同步，状态包括最近行情、心跳、持仓和订单；无行情时等待，不能产生虚构成交。增量成交要求模型开盘时刻晚于实际启动/恢复及信号观察时刻，不补记暂停期间或首次观察之前的成交。重启服务后会话保守暂停，账本和游标保留。

增量跟盘支持 CSV 新数据同步与可选 Tushare 盘后日线适配。服务端配置 `TUSHARE_TOKEN` 后重启，接口需要同时具备 `daily` 和 `stk_limit` 权限；配置存在不等于连接已验证。日线同步不属于盘中实时交易。未配置外部行情时仍可导入真实历史数据及测试本地执行流程。

当前无券商连接或真实交易能力，本地模拟撮合不能视为券商成交回报。云端常驻运行及真实行情/券商账户联调分别验收。详情见 [API契约](docs/phase-2-api.md)、[设计范围](docs/phase-2-design.md) 和 [阶段索引](docs/phase-2-index.md)。

## Phase 4：免费最新行情与持仓估值

打开「模拟盘」顶部的「最新行情与持仓估值」，直接搜索股票名称或代码，点击股票查看报价。默认使用本机已有的沪深300股票池；没有股票池时可输入 `600000.SH` 等完整沪深A股代码。**不需要Tushare、第三方账号、CSV或先建立策略/模拟账户。** 股票池是已导入的单时点成分名单，不自动更新为每日成分。

行情来自腾讯公开快照，显示价格、相对昨收涨跌、供应商快照时间、收到时间、最近成功取得时间，以及交易时段、闭市、过期或故障状态。来源时间不是本机抓取时间，也不是逐笔成交时间。闭市显示最近有效收盘快照；2026年长假按[上交所公布的休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)判断，日历范围之外明确显示未知并停止有效估值。零成交量不被直接认定为停牌。

可见的模拟盘页面每 **45秒** 自动刷新，也可点「刷新报价与估值」。页面隐藏或切换工作区时暂停页面轮询，返回时刷新。所有页面及账户共用服务端缓存；手动刷新也遵守限流，源失败会退避。本地服务运行时，独立后台每45秒检查增量账户持仓（包括暂停账户），以及最近120秒页面关注过的股票；关闭页面后持仓仍刷新，退出本地服务后停止。公开接口可能延迟、限流或停供，旧报价保留为参考时会标明状态，不冒充新鲜行情。

有「增量跟盘」账户时，可逐个选择查看现金、持仓市值、最新总资产和持仓浮盈亏。计算使用该账户实际股数及账面成本；持仓均价沿用已记费用。空仓时总资产就是现金；任何持仓缺少有效报价时，完整总资产和浮盈亏暂不计算。不同账户不会合并，历史回放与Backtrader账户不纳入这里的最新估值。

**报价更新只更新展示，不触发新的盘中策略买卖，也不重写历史净值、订单、成交、游标或冻结策略。** 原日线模拟和历史回放继续按各自规则运行。公开快照和复权研究数据不会因此变成严格撮合数据。当前真实探测在闭市完成，已证明最新可得报价接通；盘中连续价格变化尚未现场观测，隔离测试替身不作为盘中实测证据。

本阶段未新增运行依赖、账号或付费服务。2026-11-10已完成独立基本验收和本机正式部署：211项测试、9组独立检查、4轮浏览器通过，正式数据库保全。实现/API和真实网络证据见[实施记录](docs/phase-4-implementation.md)，完整验收与备份部署记录见[阶段索引](docs/phase-4-index.md)。

## 配置本地 ASR

首次配置可复制 `.env.example` 为 `.env`；已有 `.env` 时只更新 ASR 字段，保留其他配置。填写 `ASR_MODEL_PATH` 指向**已下载的 faster-whisper / CTranslate2 模型目录**，目录内应有 `model.bin`、配置、词表等配套文件。不能直接使用原版 Whisper 的 `.pt` 文件。

```dotenv
ASR_MODEL_PATH=C:/models/faster-whisper-small
ASR_DEVICE=cpu
ASR_COMPUTE_TYPE=int8
```

若还没有模型，可自行显式运行下载命令（会联网下载模型文件；应用、安装脚本都不会自动执行）：

```powershell
.venv/Scripts/python.exe scripts/download_asr_model.py --model small --output data/models/faster-whisper-small
```

CPU `int8` 为默认配置；中文术语、证券简称和数字仍需人工校对。较小模型更省资源，但质量可能下降。GPU 环境需要自行安装兼容 CUDA/cuDNN 并更改设备配置。faster-whisper 通过 PyAV 解码，本地上传转写不依赖系统 FFmpeg。单文件默认 200MB，最长 120 分钟；超长材料应拆分。媒体子进程最长运行 1 小时，超时会中止并保留可重试的任务记录。

当前 faster-whisper 1.2.1 需搭配 `av<19`，项目依赖已限制该范围，本机验证版本为 PyAV 18.1.0。若曾安装 PyAV 19，请重新执行 `.venv/Scripts/python.exe -m pip install -r requirements.txt`；否则模型可能加载成功，但音频解码因 `metadata_errors` 参数不兼容失败。修改 `.env` 后需重启服务。模型就绪后，新上传媒体自动排队转写；已有缓存点击“开始转写”即可，无需重新下载。配置、来源哈希及真实验证记录见 [ASR 补充记录](docs/phase-1-supplement-asr.md)。

## 配置策略提取接口

在网页顶部“运行配置”中选择供应商、模型 ID 与接口地址，输入 API Key 后点击“保存到本机”。预设提供 OpenAI、DeepSeek、Qwen、Kimi、GLM 及自定义兼容接口；模型 ID 可编辑。再点击“测试已保存连接”发送一次轻量请求。**保存不代表连通，连接成功也不证明策略或纠错质量。** 修改网页配置无需重启服务。

本机 Windows 使用当前用户 DPAPI 加密保存 Key；已保存密钥不回传网页、不写入资料导出或日志。更换供应商或 API 地址必须重新填写对应 Key，避免把旧凭据送到新地址。Key 不经过产品云端；调用时认证凭据和待处理内容会发到选定的模型供应商。该 Demo 的安全凭据持久保存目前限定 Windows，其他系统不能静默降级为明文保存。

旧 `.env` 模型配置保留为未使用网页配置前的兼容路径；网页删除配置会保持禁用状态，避免旧环境凭据自动重新生效。旧 OpenAI 兼容配置示例：

兼容 OpenAI Chat Completions 的接口：

```dotenv
AI_PROVIDER=openai
AI_BASE_URL=https://your-provider.example/v1
AI_MODEL=your-model-name
AI_API_KEY=your-key
```

适配器向 `/chat/completions` 发送 `messages` 与 `response_format: {"type":"json_object"}`。要求服务支持 JSON 输出模式；返回结构为 `choices[0].message.content`。部分服务并非完全兼容，出现 400 时请确认是否支持这些参数。

Ollama 本地接口：

```dotenv
AI_PROVIDER=ollama
AI_BASE_URL=http://127.0.0.1:11434
AI_MODEL=your-installed-model
AI_API_KEY=
```

需要先安装并启动 Ollama，自己准备可用模型。适配器调用 `/api/chat`，传入 schema 和 `stream:false`。本项目不下载/启动大语言模型，也不提供伪造的默认模型。

点击“提取策略”时会将当前转写发送至配置的模型服务；使用远程接口意味着文本离开本机，服务可能产生费用。仅导入、保存和编辑文本不调用模型。AI 请求超时 180 秒，单次最多 50000 字；超长材料明确拒绝，不静默截断。

## 草案的可信边界

- 输出只允许固定字段、固定规则类型、证据和问题列表；额外字段、代码围栏、重复 JSON 字段、不匹配原文的引用会被拒绝。
- 每条规则与标的/周期值必须逐字摘自引用，避免模型补造参数；时间由服务端从转写填入，模型不能提供自己的时间。
- 未提取到买入、卖出、仓位、止损、标的、周期时，服务端自动补充待澄清提示。对“适量”“突破”“放量”等表述增加核对提示。
- 每份提取草案固定 `status: draft`、`executable: false`。Phase 2 将用户明确配置并确认的可执行映射另存为组合版本；原始草案不会自动成为可执行订单，也不会执行模型生成代码。
- **引用校验不是语义正确性的证明。** 模型可能误分规则类型、漏掉条件、选择不恰当的引用或标题。模糊检测也是保守的词表检查，不能穷尽歧义；所有规则均标为待人工复核。
- 转写是单独的“不可信数据”用户消息，系统提示要求忽略其中的指令。本次测试验证了消息隔离和输出约束；没有宣称真实模型对所有提示注入都免疫。

## 平台下载与失败处理

使用 yt-dlp 的 Bilibili/Douyin 媒体解析与下载能力。服务端从纯链接或最多10000字符的分享文案中提取唯一有效 HTTPS 单视频/短链接，归一化域名、去除追踪参数；保留 B站 `?p=2` 等明确分P，不指定时使用平台默认的第一P。相同规范链接重复出现只算一个；不同视频或不同分P同时出现时明确拒绝，不静默选第一个。短链接在后台解析，解析后再次检查单视频页面。登录、验证码、地区限制、付费视频、失效链接或平台改版都可能失败。应用不会读取个人浏览器 Cookie、登录账户、`.netrc` 或平台密码。

抖音通过全新匿名 Chrome 页面自然建立公共访客会话，再将匹配视频的媒体详情仅经内存交给下载器。需要 **Node.js 20或更高、已安装的Google Chrome**，并在项目目录运行 `npm ci --ignore-scripts`。`package-lock.json`锁定项目自己的`playwright-core`依赖及完整性，不依赖Codex内部库或`NODE_PATH`；不另行下载浏览器。缺失依赖会明确提示安装。B站下载和本地上传不需要浏览器依赖。独立CLI源码包包含浏览器桥与依赖声明；现有基础Docker镜像未安装Node/Chrome，若需要其中的抖音流程须另行配置这些运行时，不能把桌面实测视为容器验收。

独立CLI只将已发现的Node运行时目录加入隔离worker的PATH。Windows下使用系统级Chrome安装，保留程序安装根目录并创建本次运行的空AppData目录；个人配置、代理、密钥、`NODE_PATH`和`NODE_OPTIONS`不继承。

匿名浏览器通过临时本地CONNECT转发访问已知平台资源，出站IP保持公网检查和固定，TLS由Chrome验证，不解密流量。匿名初始化最多120秒，转发最多80MiB、32个并发连接，结束或父任务取消后关闭专用浏览器。应用不保存访客Cookie、临时媒体URL，不自动处理人机验证或登录；平台要求验证时停止，仍可上传自己有权使用的音视频或字幕。

一期下载优先选择单个 HTTP(S) 音轨，其次选择单文件媒体，不处理直播、合集以及必须借助外部下载器/HLS/DASH 合并的格式。下载进程检查实际出站连接地址，阻止内网、回环、保留地址与 DNS 重绑定；重定向与 CDN 请求也经过检查。下载过程不使用 shell 或外部下载器。

当平台及已列入范围的 CDN 域名解析失败，或系统 DNS 只返回 `198.18.0.0/15` 合成地址时，下载子进程会通过固定公网地址、校验证书的 HTTPS DNS 查询获取公网 IPv4（AliDNS，失败时 Google Public DNS）。只发送所需域名，不发送视频链接或 Cookie；不修改系统 DNS/代理。其他内网/保留地址仍拒绝，公共解析结果与每次实际连接继续检查并固定 IP。正常公网 DNS 沿用原路由。平台提供多个格式时，会先小范围检查所选格式的可用性，首选音轨不可用时继续选择可用音轨/单文件媒体；测试文件留在该任务隔离目录并由下载器清理，任务大小、时长与超时限制继续生效。

下载与转写保留独立任务记录，在已配置 ASR 时自动连续执行。平台标题、来源链接、实际容器时长、媒体类型及文件大小仍保存在资料中；自定义资料标题不会被平台标题覆盖。页面不创建音视频播放器，媒体缓存继续用于转写重试。本地上传及首次打开缺少元数据的历史缓存仍可在受限子进程中读取实际类型、时长与大小，不改动旧转写、版本或草案。单次探测最长30秒，只允许本地file协议并检查大小/时长；失败保留原文件。

大小和时长在平台元数据、下载进度以及完成后的实际媒体检查中限制；无法确认时长、缺少音轨、直播、合集或不支持格式会明确失败。网络、平台限制、解析失败使用固定中文提示，不显示原始第三方异常或带令牌的请求地址。

任务依次在后台处理，当前阶段在页面上显示。获取失败可点击“重试获取”；转写失败保留缓存，点击“重试缓存转写”只读本机缓存，不重新下载。缓存文件丢失时提示重新导入，不自动联网。每份资料只允许一个排队/运行中的任务；已有转写不会通过转写入口覆盖，继续使用现有校对流程。服务重启会把未完成任务标为“已中断”，**不会自动重发付费模型请求**；由用户主动重试。转写失败保留已上传/下载媒体。任务执行中禁止修改同一份转写。下载可自动接续本地 ASR，不自动调用付费 AI。

历史参考项目 [Jack-Cherish/python-spider](https://github.com/Jack-Cherish/python-spider) 仅做静态评估，没有复制或执行其中代码，没有调用其旧 HTTP 签名/第三方解析服务。本项目继续采用独立的 yt-dlp 适配器。该仓库的 README 用途限制与未发现根许可证等事实记录在 [评估文档](docs/research/python-spider-evaluation.md)；不把公开仓库视为可直接采用的授权。

## 数据与接口

默认数据目录为 `data/`，可通过服务端 `DATA_DIR` 改为绝对路径：

- `workspace.sqlite3`：资料、转写、版本、所有草案快照与任务。
- `trading.sqlite3`：组合版本、不可变数据集、回测及本地模拟账本、行情游标和请求去重记录。
- `uploads/`、`media/`：用户上传或平台下载媒体。下载按资料/任务分目录，失败或中断的片段可能保留供排查；大小限制针对单次任务，不是总磁盘配额，当前无自动过期清理。
- `tasks/`：后台媒体任务结果。
- `ai-config.json`：本机 AI 配置及 Windows DPAPI 加密凭据；请勿上传或复制给其他人。

停止服务后可备份整个 `data/` 目录。资料和交易数据库未加密，使用本机账户文件权限保护；AI Key 单独加密且绑定当前 Windows 用户。程序面向单机单用户，没有远程登录、多人权限或资料删除界面；清理磁盘前请备份，避免在运行时手动改数据库。

离线可用的只读 API 文档：<http://127.0.0.1:8765/api/docs>。页面通过本地脚本读取当前服务的接口定义，可展开查看请求、响应和数据模型，不提供在线试调用；不依赖外部 CDN。完整机器可读定义为 `/openapi.json`。主要接口：

| 接口 | 用途 |
|---|---|
| `GET /api/status` | 不含密钥的配置状态 |
| `GET /api/documents` | 资料列表（最近500份） |
| `POST /api/documents/text` | JSON `{title,text,is_demo?}` |
| `POST /api/documents/upload` | multipart `file`、可选 `title` |
| `POST /api/documents/url` | JSON `{title?,url}`；url 可为完整分享文案，返回独立 download 任务 |
| `POST /api/documents/{id}/transcribe` | 手动转写缓存；缺模型/缓存或存在活跃任务/已有转写时返回409 |
| `GET /api/documents/{id}` | 转写、草案、任务及 `has_media`、`media_status`、`media_metadata`；不暴露磁盘路径 |
| `PUT /api/documents/{id}/transcript` | JSON `{revision,segments:[{id,text,start?,end?}]}` |
| `POST /api/documents/{id}/extract` | 后台提取，返回任务 ID |
| `GET /api/jobs/{id}` | 查询任务状态 |
| `POST /api/jobs/{id}/retry` | 重试失败/中断任务 |
| `GET /api/documents/{id}/export` | 下载当前版本策略 JSON |
| `GET /api/documents/{id}/media` | 本地媒体播放 |

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/check_environment.py
node --check frontend/app.js
```

沙盒环境若系统临时目录不可写，可用新的项目内临时目录：

```powershell
$run = Get-Date -Format yyyyMMdd-HHmmss
.venv/Scripts/python.exe -m pytest -q --basetemp=.runtime/pytest-$run -p no:cacheprovider
```

浏览器验收脚本需要 Node.js 和 `playwright` 包及浏览器，可通过 `NODE_PATH` 指向已安装的包；本机使用 Codex bundled package 与 Chrome：

```powershell
$env:PLAYWRIGHT_CHANNEL='chrome'
node scripts/ui_smoke.cjs
```

脚本使用 8766 端口（占用即退出，可用 `UI_TEST_PORT` 覆盖）、隔离的 `.runtime/ui-*` 数据目录以及**测试专用下载/ASR/策略替身**。成功下载画面使用生成的1秒 WAV，元数据明确写明测试用途；本地上传回归使用3秒有效WAV/H.264文件、真实PyAV子进程探测和Chrome播放，另检查历史证据定位及无效文件回退。启用模型的标记文件不含模型权重。截图和模拟 JSON 位于 `output/playwright/`；生产启动器不使用该提供方。开发实际验证范围见 [VERIFICATION.md](VERIFICATION.md)。

代码分层：`app/adapters/` 为下载/ASR/AI 适配器；`app/jobs.py` 调度媒体子进程；`app/store.py` 为 SQLite；`app/validation.py` 校验引用；`frontend/` 为无构建步骤的页面。以 `requirements.txt` 安装受限版本范围；`requirements-lock.txt` 记录本次验证环境的精确版本（包含测试依赖）。
